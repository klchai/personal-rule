## 范围和例外

- `icbc-asia.icbc.com.cn`、`mobilehk.icbc.com.cn` 归入 HK_Bank，CN_Bank 已移除对应精确规则并将它们加入排除清单。CN_Bank 的 `icbc.com.cn` 后缀仍会匹配这些地址，因此必须将 HK_Bank 放在 CN_Bank 之前。
- `bankofchina.com`、`bankcomm.com`、`ccb.com`、`cmbchina.com`、`icbc.com.cn` 等主域名可能共用境内外子域名；本规则无法保证每个子域名都是大陆业务。需要独立策略时，应在 CN_Bank 之前添加更具体的境外规则。
- 筛除条目中的十二个香港相关独立域名归入 HK_Bank，其中 `bochk.com`、`cmbwinglungbank.com` 原已存在。其他地区域名继续排除；香港集团共用域名可能覆盖大陆或其他地区业务。详见 [HK_Bank 筛查记录](../HK_Bank/README.md)。
- 排除项写入同步脚本，已建立八个完整上游快照；后续新增条目通过同步 PR 审核，仍需检查境外业务。
